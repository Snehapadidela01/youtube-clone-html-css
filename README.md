# 📺 YouTube Clone – HTML & CSS Project

## 📌 Overview
This project is a YouTube homepage clone built using HTML and CSS. It recreates the basic layout of YouTube including header, sidebar, and video grid.

---

## ✨ Features
- YouTube-style homepage layout  
- Sidebar navigation  
- Video grid section  
- Header / navigation bar  
- Clean UI using HTML & CSS
